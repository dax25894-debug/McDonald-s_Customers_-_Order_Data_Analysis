## Data Quality Correction
The dataset used in this project was AI‑generated. During validation, I discovered that the total_amount column in the orders table did not match the mathematically correct totals derived from item quantities and menu prices.

To ensure data accuracy, I recalculated all order totals using the formula:
           <p style="text-align:center;">correct_total = ∑(quantity * price)</p>
I then updated the total_amount values in the SQL database using a join between order_item_dim and menu_dim. This correction ensures that all totals in the project are consistent, reproducible, and based on reliable source data.

# The Analysis

After cleaning and correcting the dataset, I performed several analyses to understand customer behavior, order patterns, and revenue distribution.

### 1 Which cities and menu items are the top revenue drivers for the business?

```sql
-- This query count the number of customers by the City
SELECT 
    city,
    COUNT(*) AS total_customers
FROM customers_dim
GROUP BY 
    city
ORDER BY 
    total_customers DESC
LIMIT
    3

-- This query count the sum of revenue generated by the menu item
SELECT 
    m.item_name,
    SUM(oi.quantity * m.price) AS total_revenue
FROM 
    order_item_dim oi
JOIN menu_dim m ON oi.item_id = m.item_id
GROUP BY 
    m.item_name
ORDER BY 
    total_revenue DESC
```
